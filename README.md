# CALENDRIER

A small calendar in Java, displaying all the days of a month at a glance.

## About The Project

Built for the ENI course "La programmation orientee objet avec Java" (Module 2 - Using Java classes). The goal is a small calendar allowing you to view every day of a month at a single glance. Made from scratch following specific instructions.

### Status

Completed.

### Built With

- Java

## Getting Started

Compile and run with a JDK:

```sh
javac *.java && java <MainClass>
```
